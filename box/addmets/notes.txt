This directory is for including custom scripts that can evalulate a PDB and
output specified metrics. These trigger at the end of rfd_chain if you apply the
--addmets option.

For these scripts to be properly applied during rfd_chain, they must meet the
following requirements:
 1. Be an executable file (include the shebang for language specification)
 2. Accept the input PDB as the first argument
 3. Print any number of metrics onto the terminal in the following format:
    metric1 metric1_value
    metric2 metric2_value
    ...

For example, try the calc_molar_abs.sh in this directory on one of the clean
PDBs provided at examples/inputs.

./calc_molar_abs.sh $PIXI_PROJECT_ROOT/examples/inputs/1a53_clean.pdb

For these scripts to be applied during rfd_chain or evo_rfd_chain, add the option
--addmets. For example:

# Run from the examples directory
mpros inputs/1a53_clean.pdb --relax --ca_stdev 1 --addmets calc_molar_abs.sh
