This directory is for including custom scripts that can evalulate a PDB and
output specified metrics. These trigger at the end of mpros.

For these scripts to work, they must do the following:
 1. Be an executable file with a shebang
 2. Accept the input PDB as the first argument
 3. Output any number of metrics into the terminal in the following format:
    metric1 metric1_value ...
    metric2 metric2_value ...

For example, try the calc_molar_abs.sh in this directory on one of the clean
PDBs provided at examples/inputs.

./calc_molar_abs.sh $PIXI_PROJECT_ROOT/examples/inputs/1a53_clean.pdb
